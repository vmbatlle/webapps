Guía rápida

Cómo usar el filtro

  1. 1
    Busca o carga tu horario:

    O también puedes cargar un archivo ICS manualmente (tras descargarlo desde Horarios EINA).

  2. 2
    Ajusta los filtros para personalizar tu horario.

    Puedes seleccionar o deseleccionar asignaturas, grupos y tipos de docencia.

  3. 3
    Aplica los filtros y revisa el resultado.

    Pulsa «Aplicar Filtros» para actualizar el resumen, el calendario y el detalle diario.

  4. 4
    Guarda tu horario personalizado.

    Pulsa «Guardar ICS» para descargar solo los eventos que has dejado seleccionados.
